# 🎬 Frame Rate

**Frame Rate** is a movie database web application built with React that allows users to discover, like, and rate movies using data fetched from the [TMDB API](https://www.themoviedb.org/). Inspired by platforms like IMDb, Frame Rate offers a clean, interactive user interface for exploring trending films, reading movie details, and organizing favorites.

🔗 **Link**: [https://frame-rate.netlify.app/](https://frame-rate.netlify.app/)

## 🚀 Features

- 🔍 **Browse Movies** – View popular, top-rated, and upcoming movies
- 🎞️ **Movie Detail Pages** – See overviews, release dates, ratings, posters, and more
- ❤️ **Like and Rate** – Add movies to your favorites and give your personal rating
- 🧠 **React-Powered UI** – Fast and responsive user experience with component-based architecture
- 🌐 **TMDB Integration** – Real-time data from the Movie Database API

## 🛠 Tech Stack

- **Frontend**: React, JavaScript, HTML, CSS
- **API**: [TMDB API](https://developers.themoviedb.org/3)
- **Icons**: FontAwesome
